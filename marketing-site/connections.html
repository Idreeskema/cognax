A clear list of what is connected

Create a connection from the Connections page, then manage it from the menu on its row. Filter the list by type, check whether each source is ready, and tag connections to keep them organized.

Excel is the connection type available today.

What every connection tells you

Type
What kind of source it is. Excel today, so you can tell it apart from what comes later.
Status
Whether the source is ready to use, so you do not build a report on something still processing.
Tags
Your own labels, such as sales or finance, for finding the right source in a long list.
Created and last changed
When it was added and when it last changed, so you know how fresh a source is when a number looks off.
